## Distillation Contract

```yaml

  enabled: True
  foreground_focus: True
  fg_weight: 1.0
  bg_weight: 0.01
  box_scale: 2.0
  min_fg_pixels: 4
```

Code behavior:

- `RTv4Criterion.loss_distillation()` reads `foreground_focus`, `fg_weight`, `bg_weight`, `box_scale`, and `min_fg_pixels`.
- `DetSolver.fit()` uses `enabled` only for the old adaptive gradient logging/weight-adjust block.
- v2.2 sets `enabled: True` to avoid ambiguous config semantics.
- `DetSolver.fit()` has been made robust when `rho/delta/default_weight` are not provided.
